# RailSaathi — IRCTC Simplified

A polished, dependency-free hackathon MVP for a simpler Indian railway booking experience.

## Run locally

Open `index.html` in a modern browser. No build step, API key, backend, or real IRCTC account is required.

## Demo journeys

- Smart Search: compare deterministic train options by price, duration, confirmation likelihood, and preference.
- Travel Agent: turn natural language into a structured trip plan and an approval-gated mock booking.
- Status Translator: explain GNWL, RAC, RLWL, PQWL, and CNF in plain language.
- Tatkal Mode: readiness checklist, countdown, deterministic mock result, and fallback choice.
- My Bookings: view confirmed and RAC mock bookings.
- Language selector: English, Hindi, and Telugu hero copy.

All booking behavior is simulated; no irreversible booking or payment action is performed.
